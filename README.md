# 词间 · Wordloom

Interactive static vocabulary-app prototype using the 11 user-authored learning cards. No quiz or automatic mastery inference. Browse, search, navigate, and edit mnemonic stories. Edited stories remain in the current browser's localStorage. New-word AI generation and cross-device synchronization are not connected.

The canonical vocabulary content comes from the parent workspace's vocabulary-app-design.md. Only the extracted word cards are included in this site. `dist/` contains the authored public files; no build or dependencies are required.
